# 🌍 GeoMobility360 AI

### Geospatial Intelligence, Smart Mobility & Urban Analytics

**GeoMobility360 AI** est un projet de Data Science et d'intelligence géospatiale consacré à l'analyse des territoires, des mobilités urbaines et des opportunités d'implantation commerciale.

## 🎯 Objectifs

- Analyser les caractéristiques démographiques et socio-économiques des territoires.
- Étudier les réseaux de transport et l'accessibilité.
- Identifier les disparités territoriales et commerciales.
- Développer des modèles de Machine Learning pour segmenter les territoires.
- Construire un dashboard interactif d'aide à la décision.

**Périmètre initial :** Île-de-France (communes et IRIS).

**Durée prévue du MVP :** 60 jours.

## 🛠️ Technologies

- **Data Analysis :** Python, Pandas, NumPy, SQL.
- **Geospatial Analysis :** GeoPandas, Shapely, QGIS, Folium.
- **Machine Learning :** Scikit-learn, KMeans.
- **Data Engineering :** DuckDB, Parquet.
- **Visualisation :** Matplotlib, Streamlit, Power BI.
- **Versioning :** Git et GitHub.

## 📊 Sources de données

| Source | Données |
|---|---|
| INSEE | Population, emploi, revenus |
| IGN | Contours communaux et IRIS |
| INSEE BPE | Commerces et équipements |
| Île-de-France Mobilités | Réseaux et arrêts |
| OpenStreetMap | Données géographiques complémentaires |
