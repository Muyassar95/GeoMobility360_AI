# J01 — Acquisition et exploration géographique

**Projet :** GeoMobility360 AI
**Thématique :** GeoData Engineering

## Objectif

Récupérer et explorer les contours des communes d'Île-de-France avec Python et GeoPandas.

## Source

- Producteur : API Découpage administratif — data.gouv.fr.
- Territoire : Île-de-France.
- Format : GeoJSON.
- Géométrie : contours communaux.

## Technologies

Python, Requests, GeoPandas, Matplotlib et Jupyter Notebook.

## Travaux réalisés

- [x] Téléchargement des données
- [x] Importation dans GeoPandas
- [x] Exploration des variables
- [x] Contrôles qualité
- [x] Première carte géographique

## Résultats à renseigner

**Nombre de lignes :** 1266

**Nombre de colonnes :** 8

**Système de coordonnées :** EPSG:4326

**Anomalies constatées :** Aucune

## Compétences acquises

Acquisition de données via API, manipulation de GeoDataFrame, inspection des données et cartographie Python.

Nettoyer les données géographiques, vérifier les identifiants communaux, travailler avec les projections et préparer les futures jointures INSEE.
